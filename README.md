# Палата № 13

Браузерный текстовый квест с элементами визуальной новеллы. Ночью героиня просыпается в больничной палате и исследует отделение, чтобы найти выход.

## Запуск

Откройте `index.html` в современном браузере и нажмите **«Начать игру»**. Выбирать файл мира, устанавливать программы или подключаться к интернету не требуется.

На статическом хостинге, включая GitHub Pages, игра автоматически читает `карта мира.txt`. При открытии с диска используется подготовленная копия этого текста в `world-data.js`.

## Возможности

- Четыре локации с иллюстрациями и постепенно открывающейся картой.
- Четыре персонажа с маршрутами и десять разговоров.
- Исследование объектов, применение пропуска и ключа, финал.
- Семь секретов и восемь случайных событий.
- Отдельная музыкальная тема для каждой комнаты, громкость и плавная смена.
- Адаптивное оформление и управление мышью, касанием или клавиатурой.

## Изменение истории

Локации, объекты, персонажи, диалоги, события, секреты и связи предметов описаны в обычном UTF-8 файле `карта мира.txt`. Полный формат и проверка прохождения — в `ПРОЧИТАЙ МЕНЯ.txt`.

После правок TXT обновите копию для запуска с диска:

```powershell
node build-world.cjs
```

Команды разработки требуют Node.js. Перед использованием проверьте его наличие командой `node --version`. Игрокам Node.js не нужен.

## Проверки

```powershell
node tests.cjs
node tests-map.cjs
node tests-secrets.cjs
node tests-events.cjs
node tests-music.cjs
node tests-loading.cjs
```

Необязательный локальный сервер: `node server.cjs`, затем откройте `http://127.0.0.1:8013`. Остановка — Ctrl+C.

## Файлы и медиа

`index.html`, `styles.css`, `app.js`, `world.js`, `load-world.js`, `world-data.js`, `music.js` и `map-icons.js` составляют приложение. Папка `media` содержит JPG-иллюстрации и оригинальные музыкальные WAV-петли. Исходные промпты иллюстраций — в `media/Промпты.txt`, партитуры и синтезатор — в `compose-music.cjs`.
